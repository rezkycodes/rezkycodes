### 🏗️ Architecture & Development Philosophy

I design systems and workflows with **scalability, maintainability, and productivity** at the core:

- 🏛️ **Laravel Monolith** — battle-tested, all-in-one architecture for complex business logic, rapid development, and stunning admin panels with Filament.
- 📦 **Decoupled Monorepo** — modern TS stack with shared types/configs, separating Hono-powered edge APIs and modern frontends.
- 🎨 **Vue/Nuxt or React/Next.js** — top-tier meta-frameworks for modern, reactive UI with SSR/SSG capabilities.
- 🤖 **AI-Augmented Development** — utilizing structured prompt engineering, custom AI rules/skills, and terminal-first agentic tools to accelerate coding, debugging, and architecture planning.
- 🧱 **Prisma + PostgreSQL** — type-safe data layer for TS stacks; **Eloquent** for Laravel.
- 🚀 **Upstash Redis** — serverless caching for speed at scale.
- 🐳 **Containerized Deployment** — Dockerized workflows for consistent, reproducible environments.
